DESCRIPCIÓN BREVE
    Descubre y muestra scripts de colores ANSI en PowerShell.

DESCRIPCIÓN DETALLADA
    ColorScripts-Enhanced es un módulo multiplataforma de PowerShell con miles de
    scripts de colores. Es compatible con Windows PowerShell 5.1 y PowerShell 7.x en
    Windows, macOS y Linux.

    La mayoría de los scripts de colores incluidos contienen contenido estático determinista y se
    renderizan en el mismo proceso, sin iniciar un proceso secundario de PowerShell. La caché
    de salida se limita al pequeño conjunto de renderizadores costosos seleccionado en
    CachePolicy.psd1. Los renderizadores que deben mostrar datos actuales no se almacenan si
    reutilizar su salida cambiaría su comportamiento.

USO BÁSICO
    Import-Module ColorScripts-Enhanced
    Show-ColorScript
    Show-ColorScript -Name bars
    Get-ColorScriptList -Category Patterns

    Los scripts de Pokémon se excluyen de la selección aleatoria de forma
    predeterminada. Usa -IncludePokemon para incluirlos. Un nombre solicitado
    directamente sigue funcionando.

COMANDOS
    Show-ColorScript
        Muestra un script de colores aleatorio o por nombre. Alias: scs.

    Get-ColorScriptList
        Consulta scripts por nombre, categoría o etiqueta.

    New-ColorScriptCache
        Crea caché solo para los renderizadores seleccionados por la política.

    Clear-ColorScriptCache
        Elimina entradas concretas o toda la caché del módulo.

    Add-ColorScriptProfile
        Agrega al perfil de PowerShell un bloque de inicio idempotente.

    Get-ColorScriptConfiguration, Set-ColorScriptConfiguration,
    Reset-ColorScriptConfiguration
        Lee, guarda o restablece la configuración del módulo.

    Export-ColorScriptMetadata
        Exporta metadatos del catálogo, archivos y caché opcional.

    New-ColorScript
        Crea una plantilla UTF-8 y orientación para sus metadatos.

CACHÉ Y CONFIGURACIÓN
    New-ColorScriptCache -All
    New-ColorScriptCache -Name Galaxy
    Clear-ColorScriptCache -All
    Get-ColorScriptConfiguration

    Consulta Get-ColorScriptConfiguration para obtener la ruta efectiva de la
    caché. Define COLOR_SCRIPTS_ENHANCED_CONFIG_ROOT antes de importar el módulo
    para mover la configuración persistente.

AYUDA Y VERSIÓN
    Todos los comandos exportados aceptan -h (alias -help) para ayuda breve.

    Get-Help Show-ColorScript -Full
    Get-Help Show-ColorScript -Examples
    Get-Module ColorScripts-Enhanced | Select-Object Version

    El manifiesto del módulo es la fuente de versión autorizada.

CODIFICACIÓN Y PROCEDENCIA
    Los scripts de PowerShell generados usan UTF-8. Los archivos .ANS tradicionales
    suelen usar CP437. El arte de terceros conserva su autoría y condiciones.
